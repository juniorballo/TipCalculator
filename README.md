# Tip Calculator 

Une application Android simple pour calculer facilement un pourboire et arrondir le montant.

##  Fonctionnalités
* Saisie du montant de la facture
* Choix du pourcentage de pourboire
* Option pour arrondir le montant
* Calcul automatique à l'écran

##  Outils
* Kotlin
* Jetpack Compose (Material 3)
